# Explorer für MQTT, OPC UA und Modbus TCP – Umsetzungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein Reiter „Explorer“ an MQTT-, OPC-UA- und Modbus-TCP-Verbindungen, mit dem man Datenpunkte live erkundet, testweise schreibt und gefundene Werte mit einem Klick als Zuordnung übernimmt.

**Architecture:** Ein gemeinsamer Rahmen (`explorer.go`) liefert Reiter, Rechteprüfung, Sitzungsgrenze (15 min, Höchstzahl je Benutzer/Server), einen SSE-Helfer, die Schreibsperre (Recht, Spiegel, Rückfrage) und den Verlaufseintrag. Je Protokoll eine Datei mit reinen, testbaren Kernfunktionen und dünnen HTTP-Handlern; Zustand nur im Arbeitsspeicher der jeweiligen Anfrage. Live-Werte per Server-Sent-Events wie beim heutigen Sniffer, Einzelabrufe als JSON. Die alten Werkzeugseiten (Sniffer, Namespace durchsuchen, Register lesen) gehen im Explorer auf und leiten dorthin um.

**Tech Stack:** Go 1.27, chi, html/template, `github.com/eclipse/paho.mqtt.golang` (auf v1.5.1), `github.com/gopcua/opcua` (auf v0.9.1, inkl. `server`-Paket für Tests), `github.com/goburrow/modbus` v0.1.0 (neueste Version des Moduls), `github.com/mochi-mqtt/server/v2` v2.7.9 (nur Tests), PostgreSQL (`record_history`).

**Spec:** `docs/superpowers/specs/2026-11-14-explorer-design.md` (freigegeben) und `AGENTS.md`.

## Global Constraints

- Sprache: alle Texte in Oberfläche, Fehlermeldungen, Handbuch, CHANGELOG, Commits auf **Deutsch**, für Anwender im Betrieb.
- Version: `VERSION` wird `0.80.11` (main steht auf `0.80.10`); neuer Eintrag `## [0.80.11] – 2026-11-14` ganz oben in `CHANGELOG.md`. Keine Nebenversion vergeben (0.77.0 ist reserviert).
- Explorer gibt es für: Import `mqtt`, `opcua`, `modbus`; Export `opcua`, `modbus`. Sonst kein Reiter.
- Lesen/Erkunden: wer die Verbindung sehen darf (`import.read` bzw. `export.read`). Schreiben/Senden: nur mit `import.write` bzw. `export.write`, mit Rückfrage (`confirm=1`), mit Eintrag in `record_history` (ref_type `connection`, action `explorer_write`) und im Server-Protokoll (`componentLog("explorer")`). Auf dem Spiegelserver (`h.Mirror().On`) nie Schreiben/Senden – Knöpfe ausgeblendet, Server antwortet 409 mit `mirrorReadOnlyMsg`.
- Keine neue Migration und kein neues Recht: die Spezifikation bindet den Explorer ausdrücklich an die vorhandenen Verbindungsrechte. Die Schreib-Routen bekommen trotzdem Einträge in `gateRules` (`perm_gate.go`).
- Grenzen: Sitzung höchstens **15 Minuten** (`explorerMaxDuration`), höchstens **3** gleichzeitige Explorer-Sitzungen je Benutzer und **20** je Server; MQTT höchstens 2000 Themen, 60 Verlaufspunkte je Thema, 4000 Byte Inhalt je Anzeige, 64 KiB beim Testsenden; OPC UA höchstens 500 Kinder je Aufklappen, 20 verfolgte Knoten; Modbus höchstens 125 Register bzw. 2000 Bits je Lesevorgang, Abfragetakt 1–60 s.
- Quellwert-Formate bleiben rückwärtsverträglich: MQTT `thema` oder neu `thema#json.pfad`; OPC UA NodeID-Text; Modbus `registertyp:adresse:datentyp` oder neu `registertyp:adresse:datentyp:reihenfolge` (Reihenfolge `abcd` wird nie ausgeschrieben).
- Modbus-Reihenfolgen: `abcd` (Standard, big-endian), `cdab` (Wörter getauscht, z. B. WAGO), `badc` (Bytes getauscht), `dcba` (little-endian). Datentypen: `int16`, `uint16`, `int32`, `uint32`, `float32`, `int64`, `uint64`, `float64`; Coils/Discrete als `bool`.
- Oberfläche: Farben, Ecken, Schatten nur über `--bg`, `--bg2`, `--text`, `--muted`, `--border`, `--accent`, `--shadow-card` (und vorhandene `--green`, `--red`, `--amber`); in Fiori und Fluent, hell und dunkel prüfen. Kopfleiste unverändert.
- Handbuch mitpflegen (`web/templates/help.gohtml`, Kapitel `connections`, Skizze in `widgets/help_figures.gohtml`); Entfallenes (Sniffer-, Vorschau-, Register-lesen-Seite) entfernen.
- Tests ohne echte Geräte; DB-Tests überspringen ohne `PDH_TEST_DSN`. Testaufruf in Git Bash:

## Review Focus

1. **Vielbeschäftigter Broker mit Filter `#`** (tausende Themen, hohe Rate): Tabelle bleibt bei 2000 Themen stehen, zählt Verworfene, Browser bekommt gebündelte Updates (alle 500 ms) statt einer Nachricht je Meldung. → Test `TestMqttTopicTableCap` in Aufgabe 2.
2. **Reiter geschlossen / Netz weg mitten in der Sitzung:** Geräteverbindung wird geschlossen und der Sitzungsplatz sofort frei, sonst sperrt sich der Benutzer nach drei Versuchen selbst aus. → Test `TestRunExplorerStreamReleasesOnCancel` in Aufgabe 1.
3. **Gerät nicht erreichbar:** verständliche Meldung nach höchstens der Zeitgrenze (Modbus 5 s, OPC UA 10 s, MQTT 6 s), kein hängender Request. → Test `TestModbusRangeUnreachable` in Aufgabe 4.
4. **Modbus-Ausnahme mitten im Bereich** (Register 990–1009, Gerät kennt nur bis 999): Fehler mit Bereich im Text, HTTP 502 mit JSON, kein 500/Absturz. → Test `TestModbusRangeHandlerDeviceError` in Aufgabe 4.
5. **Dezimalkomma beim Testschreiben** („21,5“ – so tippen Anwender im Betrieb): wird wie „21.5“ behandelt, bei Ganzzahltypen klar abgelehnt. → Test `TestExplorerDecimal` in Aufgabe 1 und `TestEncodeModbusValueComma` in Aufgabe 4.
